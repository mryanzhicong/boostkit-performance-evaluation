909: 判断 Celeborn 生效方式
910: 方式一：
911: sql 运行日志最后输出：WARN ShuffleClientImpl: Shuffle client has been shutdown!
912: 原因：ShuffleClientImpl 是 Celeborn 自己的客户端类，只有 Spark 真正切换到 Celeborn ShuffleManager 后，才会实例化并运行这个类。 看到它打日志，就说明 Spark 的 shuffle 路径已经走 Celeborn，而不是原生 Spark shuffle。同时，ShuffleClient 是 Celeborn 客户端库（celeborn-client）的核心组件，运行在 Spark Executor 进程内，只存在于 Celeborn 的 shuffle 链路里。 原生 Spark shuffle 没有这个类。

914: webui 界面，shuffle 算子的 metrics 里面没有 local 字样，只有 remote
