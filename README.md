# Performance result history

This branch is maintained by manually triggered performance workflows.
Result directories use UTC+8 time: YYYY-MM-DD-HH-MM-SS_RUN_ID-ATTEMPT.
Optimized runs are stored in an optimized/ directory below the version.
Each architecture keeps its normalized data, report, declared outputs, and original test-stage stdout/stderr in raw-output.log. Other stage logs remain in GitHub Actions artifacts.
